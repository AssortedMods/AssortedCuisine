# Assorted Cuisine

Adds cheese, chocolate, pies, sodas and other foods to cook and eat. This includes Assorted Kitchen, Assorted Sodas, Assorted Health and Assorted Dragon Fruit in one download.

If you only want some of them you can install those mods on their own instead. Your world keeps everything either way.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
