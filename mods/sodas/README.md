# Assorted Sodas

Adds sodas you bottle yourself. Make carbonated water from a soda bottle, a CO2 canister and water, then add a flavor. Each soda heals you when you drink it and some give an effect too. The spiked orange soda hurts whoever drinks it.

Also included in [Assorted Cuisine](../cuisine). Worlds made with Assorted Cuisine 1.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
